# Pictogrammes Ocean Buddy

La liste contient 13 identifiants : 26 fichiers SVG, avec une version couleur et une version `-mono` pour chacun. Canevas 48 × 48, fond transparent, encre #0B1F4D et bande de houle commune #1F5BFF ; monochromes en `currentColor`. Aucun corail utilisé. Les niveaux utilisent des barres évidées pour les niveaux non atteints.

- `all.svg` / `all-mono.svg` : Rose des vents géométrique au-dessus de la houle, pour voir tous les sports.
- `surf.svg` / `surf-mono.svg` : Planche effilée sous une vague qui se creuse.
- `bodyboard.svg` / `bodyboard-mono.svg` : Planche courte à nez arrondi, allongée en diagonale sur la houle.
- `baignade.svg` / `baignade-mono.svg` : Nageur géométrique sans visage, bras replié au-dessus de l’eau.
- `paddle.svg` / `paddle-mono.svg` : Planche longue avec une pagaie simple en diagonale.
- `kayak.svg` / `kayak-mono.svg` : Coque de kayak de profil avec cockpit et pagaie double.
- `snorkeling.svg` / `snorkeling-mono.svg` : Masque à deux verres reliés et tuba latéral.
- `plongee.svg` / `plongee-mono.svg` : Bouteille verticale avec robinet, flexible et détendeur.
- `kitesurf.svg` / `kitesurf-mono.svg` : Aile arquée, deux lignes et planche courte.
- `windsurf.svg` / `windsurf-mono.svg` : Voile triangulaire et mât sur une planche.
- `debutant.svg` / `debutant-mono.svg` : Trois barres croissantes, la première pleine et les deux suivantes évidées.
- `intermediaire.svg` / `intermediaire-mono.svg` : Trois barres croissantes, les deux premières pleines et la dernière évidée.
- `expert.svg` / `expert-mono.svg` : Trois barres croissantes entièrement pleines.
