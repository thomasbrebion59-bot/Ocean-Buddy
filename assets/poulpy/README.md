# Les compagnons Poulpy

Six illustrations créées pour Ocean Buddy avec l’outil intégré de génération d’images, à partir de la planche de personnage fournie par le propriétaire de l’application.

| Fichier | Usage |
| --- | --- |
| surf.webp | Surf, bodyboard et sports de glisse |
| dive.webp | Plongée et découverte sous-marine |
| paddle.webp | Paddle et kayak |
| travel.webp | Exploration des destinations et préparation des voyages |
| eco.webp | Défis de protection de l’océan |
| celebrate.webp | Progression et personnalisation du profil |

Format : WebP 640 × 640, transparence conservée. Les illustrations sont des personnages imaginaires ; les destinations et les spots continuent d’utiliser de vraies photographies créditées dans `photos.html`.

Le choix personnel du profil est conservé uniquement dans le navigateur, sous `oceanbuddy_poulpy_style_v1`. Le mode automatique suit l’activité choisie.
