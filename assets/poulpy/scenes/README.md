# Poulpy — scènes illustrées

Six scènes créées avec l’outil intégré image_gen à partir de Designer-40.png fourni par le propriétaire d’Ocean Buddy. Surf, plongée, paddle, exploration, écologie et célébration. Format WebP 960 × 640. Casquette unique à l’endroit ; équipement de plongée sans casquette.

Ces illustrations mettent en scène la mascotte. Les photos des destinations et des spots restent dans le catalogue photographique.
